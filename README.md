## Practical 1: Linux File Ownership and Group Management

### Commands Practised

| Command | Purpose |
| --- | --- |
| `adduser` | Creates a new user |
| `groupadd` | Creates a new group |
| `chown` | Changes file ownership |
| `chgrp` | Changes file group |
| `getent` | Retrieves group information |
| `ls -l` | Displays detailed file information |

### Practical Activities

1. Created a Linux user named `skanneth`.
2. Created a group named `cyberteam`.
3. Changed file ownership using `chown`.
4. Changed file group using `chgrp`.
5. Verified ownership and permissions using `ls -l`.
